# 内容录入规范

## 产品录入流程

### 方式一：管理后台手动录入

1. 登录后台 → 产品管理 → 新增产品
2. 选择分类（系统自动加载参数模板）
3. 填写中英文产品名称、描述
4. 填写结构化参数（由分类模板决定字段）
5. 上传产品图片
6. 保存发布

### 方式二：AI 工作台批量录入（开发中）

1. 上传产品素材（照片 + 参数文档）
2. AI 自动分析提取参数
3. 自动生成中英文描述
4. 人工确认/微调
5. 一键写入数据库

## 产品资料要求

### 必须提供

| 项目 | 格式 | 说明 |
|---|---|---|
| 产品名称 | 文字 | 中英文 |
| 技术参数 | 文档/表格 | 型号、功率、产能、尺寸、重量等 |
| 产品照片 | JPG/PNG | ≥1920×1080，全景+特写 |
| 分类 | 文字 | 属于哪个产品线 |

### 最好提供

| 项目 | 格式 | 说明 |
|---|---|---|
| 运行视频 | MP4 | 1080P，30秒-2分钟 |
| 工地现场照 | JPG/PNG | 设备实际使用场景 |
| 认证证书 | PDF/图片 | CE、ISO 等 |
| 产品说明书 | PDF | 补充技术细节 |

## 图片命名规范

```
{产品型号}-{序号}.{格式}

示例：
SC200-1.jpg    # 全景照
SC200-2.jpg    # 侧面照
SC200-3.jpg    # 特写
SC200-video.mp4 # 运行视频
```

## 翻译规范

- 默认语言：中文（zh）
- 目标语言：英文（en）
- 翻译通过后台 AI 翻译按钮自动生成
- 翻译后需人工校对专业术语
- 新增翻译 key 时只需补 zh + en

## SEO 规范

每个产品页面应包含：
- 中英文 Title（含型号 + 核心关键词）
- 中英文 Description（150-300 字符）
- 关键词标签（5-10 个）
- JSON-LD 结构化数据（自动生成）
